Where things stand

No experiment has run on MADQA yet. The lab code passes its tests on a tiny made-up corpus. Running on real data needs your Hugging Face login. Nothing here is a result of ours, and the model lists are candidates that the tests will narrow down.

The goal

MADQA has 2,250 human-written questions over 800 PDFs: 1,550 train, 200 dev, and 500 hidden test questions. The leaderboard ranks by LLM-judged accuracy on the test set.

Terms used here

Agentic RAG
A system that searches, reads, and decides for itself whether to search again before answering.
Open-weight
A model whose weights you can download and run yourself.
BM25
Classic keyword search that ranks pages by shared words, favouring rare ones.
Learned sparse
Keyword-style search where a model chooses and weights the terms, including related words.
Visual search
Search that compares the question with page images, so it can find charts and scans.
Reranker / judge
A model that rescores a shortlist more carefully than the first search could.
Expansion
SAG2's idea: take terms from the best pages so far and search again, to reach linked evidence.
Page recall@k
The share of the correct pages found within the top k results.
Accuracy
The leaderboard's ranking metric: answers judged correct, using string matching plus an LLM judge.
ANLS
How close the answer's text is to the accepted answer. Extra words lower it.
Page F1
How well cited pages match the correct pages. It penalizes both missing and unnecessary citations.
Kuiper
Whether accuracy depends on how much effort the agent spent on a question. Lower is better.
